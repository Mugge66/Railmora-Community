# Contributing feedback

Thank you for helping improve Railmora.

## Before reporting a problem

1. Install the latest public beta from [railmora.eu](https://railmora.eu).
2. Check whether the problem has already been reported.
3. Remove personal or confidential information from screenshots and project
   files.

## A useful bug report includes

- Railmora version
- Windows version
- What you were trying to do
- The exact steps that reproduce the problem
- What you expected
- What happened instead
- A screenshot or minimal sample project when safe to share

Do not publish licence keys, payment details, private correspondence, passwords
or security vulnerabilities. Send those to
[info@railmora.eu](mailto:info@railmora.eu).
