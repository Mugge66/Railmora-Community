# Security policy

Please do not create a public issue for a suspected security vulnerability,
licence bypass or exposure of personal data.

Report it privately to [info@railmora.eu](mailto:info@railmora.eu) with:

- The affected Railmora version
- A clear description of the issue
- Steps to reproduce it
- The potential impact

Railmora will acknowledge the report and coordinate any public disclosure after
a fix is available.
