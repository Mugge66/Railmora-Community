# What's New in Railmora

This page contains the public release notes for the newest Railmora version. It is the page opened by **Help > What's New** in the application.

## Railmora 9.0.0-rc.244

- **What's New is now always current.** The Help menu opens this public Railmora Community page, so release information can be updated without exposing the private application source.
- **Cleaner language selection.** Primary menus, Smart Route actions, panels, 3D tools and common commands were audited in English, German and French. The Danish **Indsæt valgt** label that could appear in the English Smart Route interface is now **Insert selected**.
- **Smart Route helix approaches remain included.** Railmora first tries direct helix placement and can then add short, real catalogue-track approaches when the direct footprint cannot fit.
- **No project conversion is required.** Project format 81 is unchanged, so projects from rc.243 open directly.
