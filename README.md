# Railmora Community

This is the public community space for [Railmora](https://railmora.eu), the
model railway layout designer for Windows.

Read [What's New in Railmora](WHATS_NEW.md) for the latest public release notes.

## What belongs here

- Questions about using Railmora
- Ideas and feature suggestions
- Reproducible beta bug reports
- Screenshots and stories from layouts designed with Railmora

## Where to post

- **Discussions:** questions, ideas and general conversation
- **Issues:** reproducible software problems
- **Private email:** licence, payment, privacy and security matters at
  [info@railmora.eu](mailto:info@railmora.eu)

## Source code

This repository contains community documentation and feedback templates only.
It does **not** contain the Railmora application source code, signing material,
release infrastructure or private development files.
